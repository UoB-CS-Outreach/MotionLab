Motion Lab network check

A throwaway diagnostic for the Motion Lab open-day activity. Run it on the lab machine, on the venue network, then download the report. Nothing runs until you press a button.

What this page does and does not do

It does:

  • Make ordinary web requests to the services this activity uses (GitHub Pages, jsDelivr, gstatic, and the Ably and Firebase relay services) and to a few alternatives we might switch to.
  • Pass short test messages (no personal data) through each relay service, from this page back to itself.
  • Record browser and connection capabilities, kept in this tab until you press Download.

It does not:

  • Scan the network, probe other machines, or touch anything on this computer.
  • Read files, cookies, browsing history, or any personal data.
  • Send results anywhere — the report is only saved if you choose to download it.
